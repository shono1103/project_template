# 計画

## 内容

案件別のタスク・QAを追加・一覧・状態変更するシェルスクリプトと固定ID方式を、
プロジェクトテンプレートへ反映する。

## 完了条件

* [x] job管理スクリプト6本を汎用例で配置する
* [x] タスク・QAテンプレートへ固定ID欄を追加する
* [x] README・入口文書・関連スキルへ利用方法を反映する
* [x] 一時案件で追加・一覧・状態変更を検証する
* [x] MEMORYを再生成する

## 結果

`job/`直下へ追加・一覧・状態変更のシェルスクリプト6本を配置し、使用例を汎用の
`PROJ-123`へ置き換えた。タスクとQAのテンプレート、README、入口文書、関連する5スキルを、
案件内固定ID（`T-001` / `Q-001`）とID優先検索に対応させた。

一時案件ではタスク・QAを各2件作成し、自動採番、pendingの依存関係、IDと旧ファイル名による
状態遷移、一覧表示、重複IDの警告と追加・遷移の拒否を確認した。Bash構文、実行権限、
`git diff --check`も正常。スキルの公式validatorはPyYAML未導入のため実行できず、
frontmatterの区切り・`name`・`description`をawkで代替検証した。
